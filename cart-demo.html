Cart UI Demo

This page demonstrates the non-invasive, idempotent ThreadlineCartUI module. It renders into a known container so repeated calls do not rewire the document.

It loads scripts/cart.js too, so the badge and drawer reflect the real, persisted cart rather than a throwaway counter — which is how a product page uses them.

The cart persists in localStorage, so reloading this page should show the same badge count and drawer contents.

Open the console to see events. Repeated calls should not create duplicate badges or handlers.
