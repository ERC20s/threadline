scripts/cart.js + scripts/cart-ui.js — browser test

Open this file served from the repository root (so relative script paths resolve). It drives the real modules against real localStorage and asserts that the badge and drawer follow the stored cart.

The cases below exist because the two modules did not agree on the shape of the threadline:cart-updated detail: cart.js published totalQuantity, cart-ui.js read count, and the badge stayed blank through every real update. cart-ui.js also ran its own tally of threadline:add-to-cart alongside cart.js's, so the badge ended up showing the last add's quantity instead of the cart total.

Notes

This test writes to localStorage['threadline_cart'] and clears it again when it finishes.
